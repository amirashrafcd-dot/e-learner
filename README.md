# e-Learner — منصة التوجيهي الفلسطيني

واجهة عربية RTL لمنصة e-Learner التابعة إلى Gaza Galaxy، تعمل على GitHub Pages وتجمع الكتب والملازم والاختبارات وأوراق العمل حسب الفرع والمادة.

## ما الجديد في هذه النسخة؟

- هوية موحّدة وعلامة SVG لـ e-Learner في صفحات الموقع.
- حركة دخول ناعمة للأقسام والبطاقات، تفاعلات hover، وتأثيرات مرئية مع احترام إعداد تقليل الحركة في الجهاز.
- مبدّل مظهر ليلي/فاتح مع حفظ الاختيار في المتصفح.
- أداة بحث ذكية في الصفحة الرئيسية تقترح المادة والفرع وتفتح المكتبة مباشرة.
- تطوير صفحة المكتبة: بحث وفلاتر حسب نوع المصدر والفصل والسنة، ترتيب الأحدث/الأقدم/الاسم، وعدّاد نتائج، وروابط مباشرة للمصادر.
- بوابة إدارة منفصلة في `control/` غير مرتبطة بقوائم الزوار، وتسمح بإضافة وتعديل وحذف المحتوى وحفظه مباشرة في مستودع GitHub من غير تنزيل ورفع `data.js` يدوياً.

## النشر على GitHub Pages

ارفع **محتويات هذا المجلد** إلى جذر مستودع `e-learner` (لا ترفع مجلد `e-learner` الخارجي نفسه كمجلد داخل المستودع). يجب أن يكون `index.html` في جذر المستودع وأن يبقى مجلد `assets` بجانبه. فعّل GitHub Pages من الفرع `main` والجذر `/`.

الموقع العام: `https://amirashrafcd-dot.github.io/e-learner/`

## ربط بوابة الإدارة بالحفظ المباشر

الواجهة الأمامية وحدها لا يمكنها تحديث GitHub بأمان؛ لذلك يوجد وسيط Cloudflare Worker في `worker/`. اتبع التعليمات الكاملة في [`worker/README.md`](worker/README.md).

ملخص الربط:
1. أنشئ GitHub Fine-grained Personal Access Token خاصاً بمستودع `e-learner` فقط مع `Contents: Read and write`.
2. انشر `worker/src/index.js` كـ Cloudflare Worker.
3. أضف `GITHUB_TOKEN` و`ADMIN_PASSWORD` كـ **Secrets** في إعدادات Worker، وليس في ملفات الموقع.
4. أضف المتغيرات العامة الموجودة في `worker/wrangler.toml`، ثم انشر Worker.
5. ضع رابط Worker في `control/config.js` مكان `REPLACE-WITH-YOUR-WORKER` وارفع الملف.
6. افتح `https://amirashrafcd-dot.github.io/e-learner/control/` وسجّل الدخول بكلمة مرور الإدارة.

بعد ذلك كل عملية حفظ تُحدّث `data.js` عبر GitHub Contents API، وتُنشئ Commit، ثم يعيد GitHub Pages نشر الموقع تلقائياً. قد يستغرق ظهور التعديل بضع لحظات.

**مهم أمنياً:** مسار `control/` غير معلن في قوائم الزوار وبه `noindex,nofollow`، لكن إخفاء الرابط ليس حماية بحد ذاته. الحماية الفعلية من خلال كلمة المرور التي يتحقق منها Worker، ورمز GitHub يبقى سرياً داخل Cloudflare. استخدم كلمة مرور طويلة وفريدة، وفعّل قاعدة Rate Limiting على `/api/*` في Cloudflare كطبقة إضافية. لا تضع `GITHUB_TOKEN` في `control/config.js` أو أي ملف JavaScript عام.

## إضافة ملفات الكتب والاختبارات

هذه اللوحة تحفظ بيانات المصدر والرابط فقط، ولا ترفع ملفات PDF إلى Google Drive. ارفع الملف أولاً إلى مجلد Drive المناسب، واضبط المشاركة إلى «أي شخص لديه الرابط — مشاهد» للملفات التي تملك حق نشرها، ثم الصق الرابط في البوابة. الاختبارات في النسخة الحالية ملفات PDF وروابط خارجية وليست اختبارات تفاعلية.

## تعديل البيانات يدوياً

يمكن تعديل `data.js` مباشرة. بنية المواد موجودة في `window.EL_CONFIG.branches`، وكل مادة تحتوي مصفوفة `resources`. أنواع المصادر: `book`, `summary`, `exam`, `worksheet`.

## فحوصات وحدود النسخة

تم إعداد وفحص ملفات HTML/CSS/JavaScript محلياً. لم يتم نشر Worker أو ضبط أسراره من حساب Cloudflare الخاص بك، ولم يتم ربط GitHub token؛ لذلك الحفظ المباشر لن يعمل قبل تنفيذ خطوات الربط أعلاه. كما لم يتم إجراء اختبار متصفح شامل على جميع الأجهزة.

### ترحيل المستودع الحالي

عند رفع هذه النسخة إلى المستودع الحالي، ارفع الملفات والمجلدات كما هي إلى الجذر مع السماح باستبدال الملفات. احذف صفحة الإدارة القديمة `admin.html` من GitHub إن كانت لا تزال موجودة؛ النسخة الجديدة موجودة داخل `control/` ولا يجب إبقاء لوحة الإدارة القديمة متاحة. الملفات القديمة المنفردة `admin.js` و`app.js` و`library.js` و`style.css` في جذر المستودع غير مستخدمة؛ النسخ المعتمدة هي داخل `assets/`.
