# e-Learner | Gaza Galaxy

منصة عربية لمصادر التوجيهي الفلسطيني، بإشراف Gaza Galaxy ومؤسسها أمير الرياشي. الموقع ثابت ويعمل على GitHub Pages مجاناً، ويستخدم Google Drive لاستضافة الملفات.

## الملفات
- `index.html`: الصفحة الرئيسية والتعريف بالمنصة.
- `branch.html`: مكتبة الفرعين العلمي والأدبي مع البحث والفلاتر.
- `admin.html`: لوحة إدارة لإضافة وتعديل وحذف المصادر وتصدير `data.js`.
- `data.js`: بيانات المنصة والمواد والمصادر.
- `assets/`: التنسيق وسكربتات الموقع.

## تشغيل المشروع
افتح `index.html` محلياً أو استخدم VS Code مع إضافة Live Server. لوحة الإدارة: `admin.html`.

## النشر المجاني على GitHub Pages
1. أنشئ مستودع GitHub وارفع جميع ملفات المشروع والمجلد `assets`.
2. افتح Settings ثم Pages.
3. من Build and deployment اختر Deploy from a branch.
4. اختر الفرع `main` والمجلد `/ (root)` ثم Save.
5. انتظر رابط GitHub Pages.

## بيانات المنصة والتواصل
في `data.js`:
- الجهة المشرفة: Gaza Galaxy.
- المؤسس: أمير الرياشي.
- البريد: `gaza.galaxy.edu@gmail.com`.
- المنهاج: فلسطين.

روابط التواصل تستخدم البريد الإلكتروني. يمكن تغيير البريد أو نص الرسالة من `data.js`.

## إدارة المحتوى
### باستخدام لوحة الإدارة
1. افتح `admin.html` في نسخة المشروع المحلية على جهازك.
2. اختر الفرع والمادة، ثم املأ بيانات المصدر والرابط.
3. أضف المصدر أو عدّل أو احذف مصدراً موجوداً.
4. اضغط **تنزيل data.js**.
5. استبدل ملف `data.js` القديم بالملف الذي تم تنزيله.
6. ارفع الملف الجديد إلى GitHub (Commit changes) لتحديث الموقع المنشور.

### يدوياً
يمكن أيضاً تعديل مصفوفة المادة المناسبة في `data.js` مباشرة. مثال:

```js
"الرياضيات": [
  {
    id: "math-book-001",
    title: "كتاب الرياضيات — الجزء الأول",
    type: "book",
    teacher: "وزارة التربية والتعليم",
    term: "الأول",
    year: "2026",
    description: "الكتاب المدرسي للجزء الأول.",
    driveUrl: "https://drive.google.com/file/d/FILE_ID/view"
  }
]
```

أنواع `type`: `book` كتاب، `summary` ملزمة، `exam` اختبار، `worksheet` ورقة عمل.

## تنظيم Google Drive
أنشئ مجلداً رئيسياً باسم `e-Learner Library` ثم مجلدين `العلمي` و`الأدبي`. داخل كل فرع أنشئ مجلداً لكل مادة، وداخل المادة مجلدات `الكتب` و`الملازم` و`الاختبارات` و`أوراق العمل`.

لربط ملف، ارفع الملف إلى Drive ثم انسخ رابط المشاركة وضعه في حقل الرابط. لا تجعل الملف متاحاً للعامة إلا إذا كان لديك الحق والإذن بنشره. يفضّل ضبط الصلاحية على "أي شخص لديه الرابط — مشاهد" للملفات المسموح بنشرها فقط.

## حدود النسخة الحالية والأمان
- لوحة `admin.html` أداة تحرير محلية داخل المتصفح. لا تحفظ تلقائياً على GitHub ولا ترفع الملفات إلى Drive؛ يجب تنزيل `data.js` ثم رفعه إلى المستودع يدوياً.
- لا توجد كلمة مرور إدارية في هذه النسخة؛ لا تعتبر صفحة الإدارة نظام صلاحيات. من الأفضل تشغيلها محلياً وعدم اعتبارها بوابة إدارة آمنة عند نشرها.
- النشر المباشر من لوحة تحكم يتطلب خدمة خلفية موثوقة مع تسجيل دخول وصلاحيات، مثل Cloudflare Worker أو خدمة مماثلة. لا تضع GitHub Personal Access Token أو Google API secrets في ملفات JavaScript العامة.
- الملفات والروابط المنشورة للعامة يمكن الوصول إليها من أي شخص لديه الرابط.
- الاختبارات في هذه النسخة روابط PDF أو روابط خارجية، وليست اختبارات تفاعلية.
- تأكد من احترام حقوق الملكية الفكرية للكتب والملازم قبل نشرها.
